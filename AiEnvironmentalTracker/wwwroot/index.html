Environmental Accounting Methodology & Constants

The AI Environmental Tracker applies peer-reviewed econometric formulas to translate token throughput into physical ecological impact indicators.

1. Energy Model: E (kWh) = TotalTokens × 0.0000003 kWh/token (0.3 Wh / 1k tok)
2. Carbon Model: Carbon (g CO₂eq) = E (kWh) × 400.0 g CO₂eq/kWh
3. Water Model: Water (mL) = E (kWh) × 1.50 mL/kWh (WUE)

LLM Observability Gateway Integration

To enable continuous environmental telemetry in your IDE or application, redirect your OpenAI-compatible base URL to this gateway:

# OpenAI Python SDK Configuration
from openai import OpenAI
client = OpenAI(
base_url="http://localhost:5000/v1",
api_key="YOUR_UPSTREAM_KEY"
)
VS Code Cline / Continue: Set Base URL to http://localhost:5000/v1. The gateway will intercept token metadata transparently without adding latency.
